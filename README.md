# GTA 5 RP HELPER

Помощник для GTA5RP: поиск по кодексам, законам и правилам сервера Murrieta.

## Для пользователей

Скачайте `GTA-5-RP-HELPER-Windows-<версия>.zip` из [последнего релиза](https://github.com/Ahienkov/CARLEONE-HELPER/releases/latest), распакуйте всю папку в доступное для записи место и запустите `GTA 5 RP HELPER.exe`.
Установка Python не требуется. Файлы внутри папки приложения должны оставаться вместе.
Приложение требует права администратора: при обычном запуске Windows показывает стандартный запрос UAC. При отказе приложение не запускается с обычными правами. Локальный EXE и новые Windows-сборки содержат соответствующий манифест; старые установленные версии получают запрос прав через обновляемый код. Уже запущенный помощник нужно закрыть и открыть заново, чтобы изменить права процесса.

- F4 показывает и скрывает запущенное окно, если клавиша не занята другой программой.
- Вызов по F4 показывает помощник без переключения фокуса: ввод остаётся в игре. Нажатие на окно помощника переключает фокус для работы с поиском и кнопками; повторное F4 скрывает окно и возвращает ввод предыдущему приложению.
- При запуске и нажатии ↻ проверяются версия приложения и изменения форума.
- В остальное время используется база на ПК. Периодических проверок нет.
- Проверенное обновление приложения устанавливается при автоматическом повторном запуске.
- При отсутствии интернета сохраняется рабочая локальная версия.
- «Законы» и «Правила» сохраняют отдельные поиск, сервер, категории, темы и позицию списка. В памяти находятся данные и поисковый индекс только активного раздела; при переключении предыдущий раздел выгружается. Неактивный раздел загружается заново из локальной базы при открытии.
- Среда выбирается выпадающим списком рядом с поиском: «Законы», «Правила», «Заработок».
- «Заработок» — отдельный локальный журнал доходов и расходов по серверам. История хранится в пользовательских настройках Windows (`HKEY_CURRENT_USER\Software\CARLEONE\HELPER`, раздел `earnings/v1`) вне папки приложения, сохраняется при закрытии и обновлениях и удаляется только вручную. Доступны итоги за всё время, день, 7/30 дней, месяц и произвольные даты. При выходе из этой среды её интерфейс выгружается.
- Внутри «Заработка» вкладка «Доходы» содержит прежний журнал. Вкладка «Перекупство» хранит отдельный список покупок и продаж: товар, цена покупки, дополнительные расходы, цена продажи и прибыль. Продажа 0 означает непроданный товар; позже выберите строку и нажмите «Отметить продажу». Период фильтруется по дате покупки. Эти сделки не добавляются автоматически в «Доходы», чтобы не считать одни суммы дважды. Хранилище сделок: пользовательский раздел `earnings/reselling/v1`.
- Цену продажи также можно ввести или исправить двойным щелчком по ячейке «Продажа» и нажатием Enter. Прибыль и статус пересчитаются, новая цена сохранится локально.
- «Общий итог» над вкладками показывает суммарные доходы, расходы и денежный баланс обеих вкладок по выбранному серверу и периоду. Цена покупки и дополнительные расходы учитываются в день покупки, выручка — в день продажи, включая товары, купленные раньше выбранного периода. Непроданные товары уже входят в расходы; прибыль сделки не прибавляется повторно к выручке.

Для вызова поверх игры используйте оконный безрамочный режим и включите «Поверх всех окон» в настройках помощника. С версии 1.0.2 системная горячая клавиша дополнена резервной проверкой состояния выбранной клавиши. Удержание клавиши не переключает окно повторно.
В эксклюзивном полноэкранном режиме отображение обычного окна поверх игры не гарантируется. Если игра запущена от администратора, а помощник — с обычными правами, Windows может ограничивать доступ к вводу; предпочтительно запускать обе программы с обычными правами.

## Для автора

Рабочая папка использует `development_mode: true` в `app_update_config.json`: опубликованные релизы не перезаписывают редактируемый код. В пользовательских пакетах режим разработки отключается сборщиком.

Чтобы выпустить обновление:

1. Загрузите проверенные изменения в ветку `main`.
2. Откройте **Actions → Publish GTA 5 RP HELPER → Run workflow**.
3. Укажите новую версию, например `1.0.1`.

Сценарий запускает тесты, собирает самостоятельную Windows-версию, проверяет её запуск и публикует релиз с пакетом обновления и `latest.json`.
Изменение кода без публикации релиза не обновляет установленные копии.

Если меняются зависимости или формат среды исполнения, увеличьте `runtime_version` в `version.json`: такие версии требуют загрузки новой Windows-сборки.

Локальный запуск из исходников: установите зависимости из `requirements.txt` и выполните `python bootstrap.py`.
