# GTA 5 RP HELPER

Помощник для GTA5RP: поиск по кодексам, законам и правилам Downtown, Eclipse, Rockford, Redwood, Murrieta, Chiliad, Mirror и Blaine.

В версии 1.0.5 «ИИ-поиск» вынесен в отдельную вкладку: вопрос по игровой ситуации получает объяснение и ссылки на статьи выбранного сервера. Доступно 5 новых запросов в сутки на аккаунт, сброс в 03:00 МСК. Повтор одинакового вопроса с теми же сервером и разделом использует личный кэш без списания лимита (до 30 дней, пока не изменена база или модель). Обычный поиск работает отдельно. Лимиты и проверка роли Discord выполняются сервисом Cloudflare Workers + D1, ключей ИИ в приложении нет.

Для 1.0.5 скачайте полную Windows-сборку: изменена среда исполнения. После обновления потребуется вход в аккаунт; заметки, финансы и избранное остаются в пользовательских настройках Windows.

Для остальных семи серверов добавлены локальные снимки официального форума от 13.11.2026: 237 тем законодательных разделов и 230 тем правил (включая общие правила проекта). База выбирается отдельно для каждого сервера; при отсутствии данных подстановка чужого сервера запрещена. В законах можно выбрать конкретный кодекс или закон. Кнопка «Источник на форуме» внутри раскрытой карточки ведёт к оригиналу; дата проверки указана в подсказке. Документы, опубликованные изображением, доступны по ссылкам на оригинал. История изменений выделена отдельно, чтобы старые редакции не выдавались за действующие статьи.

Существующая фоновая проверка форума обновляет базу Murrieta. Новые серверы используют сохранённые снимки: закрытые законодательные разделы требуют входа на форуме. Для повторного импорта `import_server_laws.py` обрабатывает экспорт содержимого страниц в `build/forum-auth`, а `import_server_rules.py` собирает открытые правила. Авторизационные данные в базу и пакеты обновления не включаются.

## Для пользователей

Интерфейс использует боковую навигацию, быстрый поиск (Ctrl+K), отдельные коллекции
избранного и нарушений. В финансовом разделе общие показатели показаны карточками,
в пустом журнале есть подсказка для первой записи. Боковая панель сохраняет ширину и размеры кнопок; при нехватке высоты
она прокручивается без скрытия подписей и элементов; вход, регистрация и профиль оформлены в общей теме.


Включены аккаунты с собственными логином и паролем, подтверждением через Discord
и обязательной ролью «Участник». Есть восстановление пароля через привязанный Discord.
Сервис работает на Cloudflare Workers + D1. Вход сохраняется между запусками;
обновление версии и чистая переустановка требуют подтверждения заново. Поведение и настройка:
[аккаунты хелпера](access_service/README.md).

Сообщество и поддержка: [CARLEONE HELPER в Discord](https://discord.gg/Z3muX6gMMa). Кнопка Discord под подписью автора открывает постоянное приглашение в системном браузере.

Версия 1.0.4 исправляет пустую вкладку «Заработок» в Windows-сборке: добавлены зависимости разделов, включая `uuid`. Нужна новая полная Windows-сборка (runtime 2); обновление только Python-файлов старую среду не исправит. Личные данные в пользовательских настройках Windows сохраняются. Перед публикацией EXE проверяются все четыре раздела, создание дохода и сделки, а также сохранение блокнота во временном хранилище.

Скачайте `GTA-5-RP-HELPER-Windows-<версия>.zip` из [последнего релиза](https://github.com/Ahienkov/CARLEONE-HELPER/releases/latest), распакуйте всю папку в доступное для записи место и запустите `GTA 5 RP HELPER.exe`.
Установка Python не требуется. Файлы внутри папки приложения должны оставаться вместе.
Приложение запускается с обычными правами, без обязательного запроса UAC. При необходимости его можно вручную запустить от имени администратора. Архив 1.0.2 пересобран без обязательного повышения прав; установленную ранее 1.0.2 нужно заменить новым Windows-архивом, поскольку номер версии не изменился, а старый EXE содержит собственный манифест запуска.

- F4 показывает и скрывает запущенное окно, если клавиша не занята другой программой.
- «Избранное» рядом с нарушениями показывает сохранённые статьи и правила. Звёздочка на карточке добавляет или убирает запись. Списки разделены по серверам и средам, сохраняются сразу в пользовательских настройках Windows (`favorite_articles`) и остаются после перезапуска и обновления. Избранное и нарушения независимы; поиск работает внутри выбранного списка.
- В списке и поиске карточки показывают краткое название и наказание. Нажмите заголовок или «Развернуть», чтобы прочитать полный заголовок и толкование статьи; повторное нажатие сворачивает текст. Поиск учитывает полное содержание и у свёрнутых карточек. Номер, наказание и раскрытый текст по-прежнему можно копировать нажатием.
- Поиск по законам учитывает похожие слова: небольшие опечатки, перестановку соседних букв и распространённые окончания. Точные совпадения показываются выше похожих; все слова запроса должны подходить. Номера статей и сокращения короче четырёх букв ищутся без исправлений. Например: «храенние оружия», «оружием». Поиск по правилам сохраняет прежнее поведение.
- В законах также используется локальный словарь синонимов и бытовых выражений: «украл» → «кража», «ствол» → «оружие», «тачка» → «автомобиль», «ограбил» → «ограбление», «наркота» → «наркотики». Совпадения через словарь идут после прямых. Словарь ограничен перечисленными в `law_search.py` выражениями; это подсказки для поиска, а не автоматическая квалификация нарушения.
- Вызов по F4 показывает помощник без переключения фокуса: ввод остаётся в игре. Нажатие на окно помощника переключает фокус для работы с поиском и кнопками; повторное F4 скрывает окно и возвращает ввод предыдущему приложению.
- При запуске и нажатии ↻ проверяются версия приложения и изменения форума.
- В остальное время используется база на ПК. Периодических проверок нет.
- Проверенное обновление приложения устанавливается при автоматическом повторном запуске.
- При отсутствии интернета сохраняется рабочая локальная версия.
- «Законы» и «Правила» сохраняют отдельные поиск, сервер, категории, темы и позицию списка. В памяти находятся данные и поисковый индекс только активного раздела; при переключении предыдущий раздел выгружается. Неактивный раздел загружается заново из локальной базы при открытии.
- Среда выбирается выпадающим списком рядом с поиском: «Законы», «Правила», «Заработок», «Блокнот».
- «Блокнот» — общие заметки для всех серверов. Кнопка «+ Вкладка» создаёт новую вкладку без заданного ограничения количества; двойной щелчок по названию позволяет переименовать её. Крестик удаляет вкладку после подтверждения, последняя вкладка остаётся. Названия, тексты, порядок и выбранная вкладка автоматически сохраняются между запусками и обновлениями в пользовательских настройках Windows (`HKEY_CURRENT_USER\Software\CARLEONE\HELPER`, ключ `notepad/v2/document`). Старый текст блокнота переносится в первую вкладку, прежний ключ `notepad/v1/text` сохраняется. Кнопка «Сохранить» позволяет повторить попытку при ошибке записи.
- «Заработок» — отдельный локальный журнал доходов и расходов по серверам. История хранится в пользовательских настройках Windows (`HKEY_CURRENT_USER\Software\CARLEONE\HELPER`, раздел `earnings/v1`) вне папки приложения, сохраняется при закрытии и обновлениях и удаляется только вручную. Доступны итоги за всё время, день, 7/30 дней, месяц и произвольные даты. При выходе из этой среды её интерфейс выгружается.
- Внутри «Заработка» вкладка «Доходы» содержит прежний журнал. Вкладка «Перекупство» хранит отдельный список покупок и продаж: товар, цена покупки, дополнительные расходы, цена продажи и прибыль. Продажа 0 означает непроданный товар; позже выберите строку и нажмите «Отметить продажу». Период фильтруется по дате покупки. Эти сделки не добавляются автоматически в «Доходы», чтобы не считать одни суммы дважды. Хранилище сделок: пользовательский раздел `earnings/reselling/v1`.
- Цену продажи также можно ввести или исправить двойным щелчком по ячейке «Продажа» и нажатием Enter. Прибыль и статус пересчитаются, новая цена сохранится локально.
- «Общий итог» над вкладками показывает суммарные доходы, расходы и денежный баланс обеих вкладок по выбранному серверу и периоду. Цена покупки и дополнительные расходы учитываются в день покупки, выручка — в день продажи, включая товары, купленные раньше выбранного периода. Непроданные товары уже входят в расходы; прибыль сделки не прибавляется повторно к выручке.

Для вызова поверх игры используйте оконный безрамочный режим и включите «Поверх всех окон» в настройках помощника. С версии 1.0.2 системная горячая клавиша дополнена резервной проверкой состояния выбранной клавиши. Удержание клавиши не переключает окно повторно.
В эксклюзивном полноэкранном режиме отображение обычного окна поверх игры не гарантируется. Если игра запущена от администратора, а помощник — с обычными правами, Windows может ограничивать доступ к вводу; предпочтительно запускать обе программы с обычными правами.

## Для автора

Рабочая папка использует `development_mode: true` в `app_update_config.json`: опубликованные релизы не перезаписывают редактируемый код. В пользовательских пакетах режим разработки отключается сборщиком.

Чтобы выпустить обновление:

1. Загрузите проверенные изменения в ветку `main`.
2. Откройте **Actions → Publish GTA 5 RP HELPER → Run workflow**.
3. Укажите новую версию, например `1.0.1`.

Сценарий запускает тесты, собирает самостоятельную Windows-версию, проверяет её запуск и публикует релиз с пакетом обновления и `latest.json`.
Изменение кода без публикации релиза не обновляет установленные копии.

Если меняются зависимости или формат среды исполнения, увеличьте `runtime_version` в `version.json`: такие версии требуют загрузки новой Windows-сборки.

Локальный запуск из исходников: установите зависимости из `requirements.txt` и выполните `python bootstrap.py`.

Автоматический выпуск: изменение `version.json` в `main` запускает публикацию только если сообщение коммита содержит `[release]`. Без этой отметки релиз не публикуется. Ручной запуск Actions остаётся доступен.
